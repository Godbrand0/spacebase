## 🎮 Project Overview

SpaceBase is a blockchain-powered Space Invaders game that rewards players with real cryptocurrency. Built on Base (Ethereum L2), players can earn $2 worth of Base tokens for each level completed without any upfront staking requirements.

### Key Features
- **No Staking Required**: Start playing immediately
- **Real Rewards**: Earn Base tokens for gameplay
- **Progressive Difficulty**: 5 levels with increasing challenges
- **Secure & Audited**: Built with industry-standard security practices

## 📖 API Documentation

The smart contract provides a comprehensive API for game interactions:

- **Player Functions**: Start games, complete levels, claim rewards
- **View Functions**: Get game state, session info, player statistics
- **Admin Functions**: Contract management and emergency controls

See the [full API reference](./api/contract-api.md) for detailed documentation.
